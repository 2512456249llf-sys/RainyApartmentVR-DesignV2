# 雨夜公寓：电脑版虚拟现实演示工程

这是基于 Unity 6 的雨夜复式公寓互动原型，目标设备为通过串流连接电脑的 Meta Quest 3。仓库保存当前设计版的场景、脚本、工程配置与可确认允许公开的素材；**不是可直接运行的安装包，也不是完整动作素材包**。

## 当前内容

- 复式公寓地图：通高客厅、厨房餐区、楼梯、二楼主卧、卫生间与次卧书房。
- 电脑键鼠备用模式与虚拟现实手柄交互。
- 人物语音对话：当前脚本使用通义千问实时语音接口，读取本地密钥；仓库不包含密钥。
- 人物视线、面部与动作控制脚本，以及家具、窗帘、道具和雨景相关代码。
- 主要场景：`Assets/_Project/Scenes/ApartmentDesignV2.unity`。

这是开发中的原型。公开版排除了来源与再分发权限尚未核实的原始动作文件，因此打开场景时，部分动画引用会显示缺失；动作、过渡及头显体验需要在补齐合法来源的素材后重新测试。旧阶段说明文件保留作开发记录，若与本说明冲突，以本说明和实际工程为准。

## 打开工程

1. 在电脑安装 Unity Hub，并安装 **Unity 编辑器 6000.3.24f1**，包含 Windows 构建支持。其他 Unity 6 小版本未在本仓库验证。
2. 下载仓库后，在 Unity Hub 选择“从磁盘添加项目”，选择包含 `Assets`、`Packages`、`ProjectSettings` 的仓库根目录。
3. 等待软件导入依赖。首次导入可能较久；依赖中有从 GitHub 获取的 UniVRM 软件包，需要联网。
4. 在项目窗口打开 `Assets/_Project/Scenes/ApartmentDesignV2.unity`。切勿运行旧说明中的绝对路径批处理文件。
5. 无头显时可先在电脑模式检查场景；虚拟现实测试需在电脑上启动 SteamVR，并在 Quest 3 上使用 Steam Link 连接。连接方式可能随软件版本变化，应以设备当前安装说明为准。

电脑模式常用操作：`W/A/S/D` 移动，鼠标观察，`E` 操作近处对象，按住空格讲话。头显模式为左摇杆移动、右摇杆分段转向和手柄交互；左手柄 `X` 键按住讲话。具体交互以当前场景和设备绑定为准。

## 配置语音

复制仓库根目录的 `qwen_secrets.example.json` 为 `qwen_secrets.json`，只在本地填写你自己的接口密钥与服务地址。`qwen_secrets.json` 已被版本管理忽略，**不要上传、截图或发给他人**。

代码默认模型为 `qwen3.8-omni-flash-realtime`。该模型可能需要业务空间专用地址；示例文件没有预填你的专用地址。未配置密钥时，场景应给出提示而非退出。联网对话可能产生接口费用。默认读取位置和回退方式可查看 `Assets/_Project/Scripts/Runtime/VoiceDialogue.cs`。

## 动作素材缺口

本地原工程有数十个动画文件，其中部分文件含 Mixamo 标识；用户尚未提供每个文件的来源记录和原始文件再分发许可。公开仓库只保留 `Assets/_Project/Characters/动画`、`自然动作`、`跪拜` 中的控制器与遮罩，排除原始动作及衍生动画文件。被排除的动作**不属于本仓库的授权范围**，仅靠注明来源不能自动获得再分发权。

需要完整重现动作时，请先自行取得相应素材并核对许可，再按原工程的动作命名、导入设置和编辑器安装脚本接入。公开版不保证在未补齐动作时通过与动画有关的测试，也不保证人物动作表现与本地试玩版一致。若将来取得明确允许公开再分发的书面许可，可以另行补充素材和来源清单。

## 构建和验证边界

可在 Unity 的构建设置中选用上述主场景生成 Windows 版本；仓库不包含现成可执行文件、缓存目录或旧构建日志。原工程有自动测试记录，但公开快照排除动作素材后，**尚未重新完整导入、构建及用 Quest 3 实机验收**。因此这里不声称公开快照已经可完整游玩。

建议先检查导入控制台的缺失引用和错误，再运行编辑器测试、构建，最后在头显内检查移动、碰撞、交互、语音与性能。
